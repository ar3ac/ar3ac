## 🚀 Progetti in evidenza

### 🛠️ [Lucius](https://github.com/ar3ac/lucius)
*Your personal gadget quartermaster.*
Una WebApp (PWA) mobile-first scritta in Python/FastAPI per eseguire comandi bash sul tuo Raspberry Pi o server Linux con un solo tap dal telefono.
- Nessuna configurazione complessa (zero YAML, zero Docker).
- Interfaccia web fluida e reattiva con supporto Dark Mode.
- Output del terminale in tempo reale tramite WebSockets.
- Installer universale per ambienti Linux (`systemd` + `.venv`).
